STRATEGY7 Task 4 audit
======================

Current conversion behavior before Task 4:
- The simple winning probes already convert correctly at depth 3:
  - queen trade: Qd4xd8
  - rook trade: Ra1xa8
  - piece trade: Be5xd6
- The real transcript winning-side position still drifts with Bf1h3.
- Quiet ordering already mildly prefers more practical stabilizing moves like Bf1e2,
  but the broader conversion guidance only meaningfully activates in simple endgames.

Main gap:
- The transcript Bh3 position is a materially winning heavy-piece conversion battle,
  not a simple endgame, so the current conversion layer is too narrow.
- That leaves the search under-informed about:
  - promotion-lane support,
  - king activation behind the main passer,
  - trade quality while ahead,
  - enemy heavy-piece checking/counterplay resources,
  - decorative minor-piece drift while converting.

Task 4 plan:
- Extend conversion guidance to advanced-passer heavy-piece wins, not only simple endings.
- Score promotion-lane support and trade quality more directly.
- Penalize unnecessary edge drift by minor/heavy pieces when it does not help conversion.
- Add a search regression so the transcript position must stop choosing Bh3.

# STRATEGY7 Task 2 audit

## Reviewed helpers

1. `chess_game/chess/defensive_endgame_guidance.py`
   - Already helps the worse side in simple endgames by rewarding purposeful checks, draw-zone king access, blockades, and direct pressure on the most dangerous enemy passer.
   - Limitation: it only activates in small endgames (`<= 5` non-king pieces), so it does not govern the heavy-piece middlegame/endgame positions from the new STRATEGY7 transcript.

2. `chess_game/chess/passer_race_guidance.py`
   - Already scores promotion urgency, clear promotion paths, king support, heavy-piece support, and cosmetic-check penalties in simple passer races.
   - Limitation: it is race-oriented and does not distinguish overloaded defending pieces or practical heavy-piece containment once both king safety and passer control matter at the same time.

3. `chess_game/chess/conversion_guidance.py` and `chess_game/chess/endgame_evaluation.py`
   - Already reward the winning side for cleaner simplification, passer support, king activation, and reduced counterplay.
   - Limitation: these winning-side bonuses can still leave the losing side under-modeled in heavier positions where practical resistance depends on stabilizing key defenders before generic activity.

4. `chess_game/chess/defensive_containment_guidance.py` from Task 1
   - Already improved the first baseline defense by rewarding direct passer containment around the b-file.
   - Limitation before this phase: it had no quiet-order bonus, treated heavy-piece geometry too coarsely, and did not explicitly score whether key defensive pieces were covered or overloaded.

## Remaining Task 2 problems found from the STRATEGY7 baseline

1. In the first baseline defense after `45. Qb3`, Task 1 already fixed the old `...a5` panic by keeping Black tied to the b-file.
2. In the later heavy-piece probe after `49. Rf1`, the engine still preferred `...Qa6`, which kept passer contact but drifted away from stronger defensive stabilization.
3. The core missing features were:
   - no structural distinction between front/behind/beside heavy-piece containment against the passer
   - no penalty for leaving critical defending pieces attacked and unsupported while already under pressure
   - no heavy-piece-specific quiet-order bonus for practical defensive moves
   - no root/evaluation reward for keeping checking and trade resources alive while defending

## Task 2 implementation targets

1. Expand heavy-piece containment scoring so it values:
   - front/behind/beside heavy-piece geometry against the dangerous passer
   - support for attacked key defenders that hold the defensive structure together
   - immediate king-danger pressure only from actual heavy-piece mating-net channels, not generic threat counters
   - retained checking / trade resources for the materially worse side
2. Feed the same containment logic into quiet move ordering so defensive search does not undervalue stabilizing moves.
3. Re-check the two transcript probes:
   - first probe must still reject `...a5`
   - later heavy-piece probe should stop choosing `...Qa6`
